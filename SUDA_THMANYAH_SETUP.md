# SUDA — Thmanyah typography adoption

The hero branding has been reordered: original image logo → «سُدى» → «مساحتك في عالم تصميم الأزياء». Typography for headings and UI text is mapped to **Thmanyah Serif Display** and **Thmanyah Sans**, respectively, with a fallback to the project's existing Arabic fonts.

## Activation requirement

The font files are **not included in this ZIP**. Thmanyah's official license allows use in web projects but restricts redistribution, separately accessible hosting and independent download of font files. Therefore this deliverable does not include or expose unauthorized Thmanyah font binaries or third-party redistribution CDNs.

Before publishing with the actual Thmanyah typeface, the project owner must arrange a license-compliant web embedding method with Thmanyah (`Ask@thmanyah.com`) and integrate that method into the project. As delivered, browsers without Thmanyah locally installed will show the existing Arabic fallback font.
